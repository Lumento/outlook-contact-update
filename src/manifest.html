Créer le manifeste de votre organisation

Le fichier est construit dans votre navigateur : rien n'est envoyé. Il contient les identifiants de votre organisation ; gardez-le en privé.

Avant de commencer

  1. Inscrivez une application dans Microsoft Entra ID (locataire unique), plateforme Application monopage, avec deux URI de redirection :

  2. Autorisations Microsoft Graph déléguées : Contacts.ReadWrite et Mail.Read, puis consentement administrateur.

Manifeste téléchargé. Chargez-le dans Outlook (complément personnalisé, à partir d'un fichier) ou, pour toute l'organisation, dans le centre d'administration Microsoft 365, Applications intégrées.
